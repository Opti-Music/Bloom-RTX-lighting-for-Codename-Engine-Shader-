# Bloom-RTX-lighting-for-Codename-Engine-Shader-
This code implements a high-quality threshold bloom pass and a built-in lens dirt mask coordinator, the dirt mask was mainly used for a mod I was working on, but since the song it was for got scrapped, I moved it here for ease of access.

To apply this to your game state or specific cameras in Codename Engine, use the Haxe implementation code
